# dsh-mcp-workbench

给官方 `@deepseek-ai/dsh-mcp-manager` 补一个**设置页界面**：在 DSH 设置里增删改、启停 MCP（Model Context Protocol）服务器，查看连接状态、重启、探测、管理凭据——不用手写 profile 配置、不用重启 `dsh web`。

## 要求

- DSH `>=0.2.2-alpha.2 <0.2.3`（`0.2.2-alpha.2`、`0.2.2-rc.1`、`0.2.2-rc.2` 已逐版本核对；同线其它版本带警告运行）。
- DSH `0.2.2-rc.2` 及以上才带官方 MCP 管理器（`mcp-manager` 条目）。更早的同线版本上本插件会显示「没有找到官方 MCP 管理器」，不提供任何操作。
- `web` profile（设置页插件）。

## 安装与卸载

```bash
dsh plugin --profile web add dsh-mcp-workbench        # 安装 / 升到 caret 范围内的最新版
dsh plugin --profile web add dsh-mcp-workbench@0.2.0  # 指定版本（升级必须显式写版本号）
dsh plugin --profile web remove dsh-mcp-workbench     # 卸载
```

安装或卸载会改变 profile 的 bundle 列表，**需要重启 `dsh web` 并刷新页面**才生效。源码开发路线用本目录的 `./install.sh` / `./uninstall.sh`。

## 使用方法

打开 **设置 → MCP 服务器**：

- **新增**：右上角 `+` 打开表单弹窗。服务器名就是官方清单里的键（工具前缀 `mcp__<名字>__` 会实时预览）；选 `stdio`（本地进程）或 `streamable-http`（远程服务），填命令/参数/工作目录/环境变量，或 URL/请求头。
- **保存即生效**：保存先以停用态写入官方清单，再用官方 `probe` 探测——**连得上才启用**；连不上就把原因留在弹窗里，配置以停用态保留，修完再保存即可。
- **启停**：每行左侧开关，直接切换官方条目里的 `enabled`；停用会立即卸载该服务器。
- **状态**：行上的标签来自官方管理器的连接状态流——`已连接 · N 个工具` / `连接中` / `重连 x/y` / `缺凭据` / `连接失败` / `已停用`。失败原因可把鼠标停在标签上查看。
- **删除**：行尾垃圾桶，确认后从官方清单移除并卸载；**不会**删除已写入的凭据。
- **工具名**：`mcp__<服务器名>__<工具名>`，所有会话与子代理都能用；改动对进行中的对话在下一步请求生效。

### 凭据

凭据模板是官方的 `${credential:KEY}`：

1. 在**环境变量** / **请求头**里点一行的 **「凭据」** 开关（URL 栏旁的「凭据」开关用于「整条地址进凭据库」）；
2. 填一个**键名**（自己取，合法形式 `[A-Za-z_][A-Za-z0-9_]*`），请求头可选前缀档位（不加 / `Bearer ` / `Basic ` / 其它）；
3. 表单下方出现**「引用的凭据」**区：填值并保存，值写进 DSH 凭据库（`~/.dsh/.credentials.yaml`），**界面永不回显**，同一个键可被多条服务器复用；
4. 凭据缺失时该服务器进入「缺凭据」状态，不会连出去。

值直接写在配置里也可以，但会明文进 profile 设置文件——密钥建议一律用凭据。

### 启动配置里的 MCP 服务器

手写在 profile `cordis.patch.yml` 或 bundle 里的 `dsh-mcp-client` 行不在官方管理器的管理范围内。本插件在页面下方以「配置文件中的服务器」只读卡片列出它们（服务器名、传输方式、地址、字段名，**不显示值**），每行可「导入」：把完整配置抄成一条待编辑的官方条目（敏感值搬进凭据库、默认停用），保存后由官方管理器接管。

同一个服务器名在 host 作用域内只能有一个实例；与启动配置重名时，页面会即时提示。

## 注意事项与已知边界

- **官方管理器缺失时不提供功能**：`0.2.2-rc.2` 之前的同线版本没有 `mcp-manager` 条目，页面只显示说明；升级 DSH 即可。
- **凭据来源为进程环境时只读**：官方凭据服务返回 `writable:false` 时，界面会说明无法在此修改。
- **删除条目不会删除凭据**：凭据可能被别的条目共用。
- **升级中间态**：改了宿主半体后、重启之前，页面可能提示宿主是旧版本；重启 `dsh web` 即可。
- **启动配置里的 `!!js process.env.X` 仍需重启**：`.env` 是进程启动快照，与本插件无关。
- **没有 OAuth 流程**：官方管理器当前不支持交互式授权，需要授权的服务器表现为普通连接失败。

# 变更记录

## 0.1.0

首个版本。

- 侧边栏工作区收起时，在标题行尾显示该工作区最值得注意的会话状态：等待处理（审批 / 审阅计划 / 回答）、进行中、已完成待查看；状态消失后自动隐藏。
- 工作区展开时保持 DSH 原生呈现，本插件不介入会话行的状态提示。
- 未分组桶同样适用；归档会话不计入。
- 指示器与 DSH 原生会话状态点同款：转圈 14px、圆点 10px，颜色与动画节奏一致。
- 同一工作区多个会话同时有状态时，按「等待处理 > 进行中 > 已完成待查看」只显示最高优先级的一个，顺序与 DSH 会话行一致。
- 鼠标移入工作区行时指示器整个消失，hover 高亮、展开箭头、行尾按钮与整行点击展开/收起完全回到原生表现。
- 尊重系统「减少动效」设置，与原生一致地停转并固定成一段静态弧。
- 侧边栏结构或客户端服务形状不符时保持 inert（fail closed）。

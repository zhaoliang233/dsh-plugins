# dsh-workspace-running-indicator

给 DeepSeek Harness Web 用的纯客户端插件：侧边栏里的工作区**收起**之后，如果它下面有会话需要你知道，就在工作区标题行尾显示一个状态点，让你在不展开的情况下也能看出哪里还需要关注。

## 功能

- **展开时完全保持原生**：会话标题前的状态提示仍由 DSH 自己渲染，本插件不介入。
- **收起时补齐信息**：工作区收起后，标题行尾显示该工作区当前最值得注意的会话状态，状态消失后自动隐藏。
- **三种状态、与对话里同款**：

| 工作区行尾 | 含义 | 与对话里一致 |
|---|---|---|
| 警告色圆点（10px） | 有会话在等你处理：等待审批 / 等待审阅计划 / 等待回答 | 同 warning 状态点 |
| 转圈（14px） | 有会话正在运行（含只有子代理在跑） | 同 ongoing 状态点 |
| 完成色圆点（10px） | 有会话已跑完、你还没打开看 | 同 done 状态点 |

- **同一工作区只显示一个**：多个会话各有状态时，按「等待处理 > 进行中 > 已完成待查看」取最高优先级，顺序与 DSH 会话行一致。
- **未分组桶同样适用**：不属于任何工作区、散在「未分组」里的会话也按同样规则显示。
- **空闲不显示**：没有任何需要关注的会话时，工作区行保持原样。
- **归档会话不计入**：归档会话在默认视图里本来就不显示，计入会造成「收起时有状态、展开却看不到是哪条会话」。
- **尺寸、颜色、动画全部照抄原生状态点**：转圈 14px、圆点 10px，颜色分别取 `--dsw-alias-label-tertiary` / `--dsw-alias-state-warn-primary` / `--dsw-alias-state-success-primary`，动画节奏 1.5s，与对话里的状态点看起来是同一个东西。
- **鼠标移入时整条消失**：hover 时指示器直接不渲染，工作区行回到宿主原本的排版——高亮、展开箭头、行尾菜单与新建按钮都和没装插件时一致；移出后指示器回来。
- **尊重减少动效**：系统开启「减少动效」时与原生一致，停转并固定成一段静态弧。
- **失败闭合**：找不到预期的侧边栏结构、或客户端服务形状不符时什么都不做，不抛错、不留空节点。

## 要求

- DeepSeek Harness Web `>=0.2.2-alpha.3 <0.2.3`；`0.2.2-alpha.3` 已核对。同一发布线的其他版本会给出警告继续运行，能力检查仍是最终依据；范围外保持 inert。
- Node.js 20 或更高版本。

## 安装

```bash
dsh plugin --profile web add dsh-workspace-running-indicator
```

卸载：

```bash
dsh plugin --profile web remove dsh-workspace-running-indicator
```

升级要显式写版本号（caret 范围不会自动升）：

```bash
dsh plugin --profile web add dsh-workspace-running-indicator@<版本>
```

源码 checkout 的 `./install.sh` / `./uninstall.sh` 只用于本机开发。

安装、卸载都会改变 profile 的 bundle 组成，需要重启 `dsh web` 并刷新页面才生效。

## 使用方法

装完即生效，没有设置项。展开工作区看具体是哪条会话，收起看行尾有没有转圈。

## 注意事项

- 一个工作区里多条会话同时有状态时只显示一个指示器，不显示数量。
- 三种「等你处理」（审批 / 审阅计划 / 回答）在收起状态共用一个警告色圆点，具体是哪一种需要展开看会话行。
- 提示是纯视觉的：收起状态下不额外提供屏幕阅读器文案；展开后每个会话行的原生状态提示仍带完整无障碍标签。
- 插件只读客户端快照，不写入任何会话数据，也不修改 DSH 源码。
- 侧边栏行高、按钮位置、展开箭头等原生排版都没有被改写；指示器是追加在标题行尾的一个独立节点，鼠标移入时整个移除，不参与行内布局。
- 「等待审批 / 审阅计划 / 回答 / 已完成待查看 / 子代理运行中」这些状态来自 DSH 客户端会话状态；若该状态源不可用，插件会退化为只显示「进行中」。
